01 — What we did

Two copies, one difference: hidden marks

First we wrote the clean tale (story.md). Then we made a marked copy that looks byte-for-eye identical but has zero-width characters and exotic spaces sprinkled through it (story-marked.md). The point was to prove the cleaner actually does the work: it must leave the clean copy untouched and return the marked copy to its exact original.

Why do these marks matter? Zero-width characters have no visual form at all — they take up no width and have no color. That makes them perfect for secretly fingerprinting where a piece of text came from. The cleaner's “Layer A” targets exactly these.

02 — Which commands ran

The actual commands

The repo's core is pure Python standard library — nothing to install. The script is service/scripts/clean_text.py, and the --stats flag emits the JSON report.

bash — watermarks-remover
# 1) Clean copy — must stay untouched $ python3 service/scripts/clean_text.py story.md -o story.cleaned.md --stats → removed_count: 0 replaced_count: 0 # nothing changed # 2) Marked copy — marks must be stripped $ python3 service/scripts/clean_text.py story-marked.md -o story-marked.cleaned.md --stats → removed_count: 49 replaced_count: 1 # 3) Verification invisible characters left in output: NONE byte-for-byte identical to the clean story?: YES
